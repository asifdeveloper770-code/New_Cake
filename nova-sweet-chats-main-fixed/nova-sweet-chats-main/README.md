# Miami Cake Studio Pro

# N.Y Nova Cake Studio — Premium Website Development Master Prompt

Create a premium, elegant, modern, conversion-focused website for **N.Y Nova Cake Studio**, a boutique cake studio serving **Miami Beach and nearby areas**.

## Primary Business Goal

The website must:

* Showcase the cake collection beautifully.
* Establish immediate trust and professionalism.
* Make the brand feel premium, elegant, clean, and sophisticated.
* Encourage visitors to place cake inquiries/orders through **WhatsApp**.
* Make it extremely easy for mobile users to contact the business.
* Present cake flavors and offerings in a visually appealing way.

## Target Audience

Local customers in Miami Beach and surrounding areas searching for:

* Birthday cakes
* Celebration cakes
* Special-occasion cakes
* Elegant custom cakes
* Premium homemade cakes

Design the experience specifically for customers who value **presentation, quality, elegance, taste, and convenience**.

## Visual Direction

Use a sophisticated luxury bakery aesthetic.

Design characteristics:

* Elegant neutral color palette
* Soft, clean background
* Premium typography
* Generous whitespace
* Minimal visual clutter
* High-quality cake photography
* Refined spacing and alignment
* Subtle animations
* Modern editorial-style composition
* Strong visual hierarchy

The website should feel **luxurious without being flashy**.

Avoid:

* Excessive gradients
* Overly bright colors
* Heavy shadows
* Cluttered layouts
* Generic bakery templates
* Excessive animations
* Cheap-looking decorative elements

## Website Structure

Build exactly 3 primary pages:

1. Home
2. Cakes & Flavors
3. Contact

## Global Navigation

Create a clean sticky navigation bar containing:

* N.Y Nova Cake Studio logo/name
* Home
* Cakes & Flavors
* Contact
* Prominent WhatsApp CTA

On mobile, use an elegant hamburger menu and keep the WhatsApp CTA easily accessible.

## Homepage

Create a visually striking hero section.

Hero should contain:

* Premium cake photography
* Strong headline communicating elegance and celebration
* Short supporting copy
* Primary CTA: "Order via WhatsApp"
* Secondary CTA: "Explore Our Cakes"

Immediately below the hero, introduce the studio with concise trust-building messaging.

Create sections for:

* Featured Cakes
* Why Choose N.Y Nova Cake Studio
* Cake Flavors
* Special Occasions
* Local Miami Beach service area
* WhatsApp ordering CTA
* Final conversion section
* Footer

## Cakes & Flavors Page

Create a beautiful visual gallery of cakes.

Each cake/card should support:

* Large image
* Cake name
* Short description
* Flavor/filling information
* Optional occasion/category
* "Ask About This Cake" WhatsApp CTA

Include the available fillings/flavors provided by the client:

* Dulce de leche
* Whipped cream
* Chocolate
* Nutella
* Guava
* Assorted fruit fillings

The gallery must be image-first and premium rather than looking like a generic e-commerce catalog.

## Contact Page

Create a simple, conversion-focused contact page.

Include:

* WhatsApp CTA
* Phone number
* Email
* Service area
* Simple inquiry form if appropriate
* Clear instructions for ordering/inquiries

Make WhatsApp the primary conversion action.

## WhatsApp Integration

Implement WhatsApp throughout the website.

Use contextual CTA messages where possible.

For example:
"Hi N.Y Nova Cake Studio, I'm interested in ordering a cake. I'd love to learn more about your available designs and flavors."

For individual cake cards, dynamically prefill a message such as:
"Hi, I'm interested in this cake: [Cake Name]. Can you please provide more information?"

Make WhatsApp buttons highly visible without being intrusive.

## Mobile Experience

Mobile-first development is essential.

Optimize for:

* iPhone
* Android
* Small mobile screens
* Tablets
* Desktop

On mobile:

* Keep buttons thumb-friendly
* Maintain readable typography
* Optimize image sizes
* Avoid horizontal scrolling
* Keep navigation simple
* Consider a persistent WhatsApp CTA
* Ensure cake images remain visually impressive

## User Experience

The visitor should understand within seconds:

1. What the business sells.
2. Where it serves.
3. Why the cakes are special.
4. What flavors are available.
5. How to order.

The entire experience should lead naturally toward a WhatsApp inquiry.

Build the website with strong local SEO foundations.

Target concepts such as:

* cakes in Miami Beach
* custom cakes Miami Beach
* birthday cakes Miami Beach
* celebration cakes Miami Beach
* custom birthday cakes near Miami Beach
* specialty cakes Miami Beach

Implement:

* Semantic HTML
* Proper heading hierarchy
* SEO titles
* Meta descriptions
* Image alt text
* Local business schema where appropriate
* Fast loading
* Mobile optimization
* Clean URLs
* Open Graph metadata

## Performance

Prioritize:

* Fast loading
* Responsive images
* Lazy loading
* Optimized image formats
* Minimal unnecessary JavaScript
* Excellent Core Web Vitals
* Accessible navigation

## Accessibility

Follow modern accessibility best practices:

* Sufficient contrast
* Keyboard navigation
* Descriptive alt text
* Proper button labels
* Semantic HTML
* Accessible forms
* Visible focus states

## CMS / Editing

The client wants full access and does not currently require a monthly maintenance plan.

Structure the site so the client can easily update:

* Cake photos
* Cake names
* Flavors
* Basic business information
* Contact information

Do not make ordinary content updates dependent on a developer.

## Final Design Goal

The final result should feel like a **high-end Miami boutique cake studio**, not a generic bakery website.

Think:
"Luxury cake photography + sophisticated editorial design + effortless WhatsApp ordering."

The website should be visually memorable while remaining simple, elegant, fast, and highly conversion-focused.
